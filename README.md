# موقع Market Code (نسخة GitHub Pages) + صفحة تحكم

موقع ثابت من غير سيرفر. التعديل من صفحة `admin.html` اللي بتحفظ على الريبو مباشرة.

## 1) النشر
1. ارفع **محتويات** الفولدر كلها على ريبو جيت هب (لازم `index.html` يبقى في أول الريبو، وفولدر `assets` بصوره).
2. Settings ثم Pages ثم Deploy from a branch ثم `main` و `/ (root)` ثم Save.
3. بعد دقيقة الموقع على: `https://USERNAME.github.io/REPO/`

## 2) تجهيز صفحة التحكم (مرة واحدة)
1. جيت هب: الصورة الشخصية ثم **Settings** ثم **Developer settings** ثم **Personal access tokens** ثم **Fine-grained tokens** ثم **Generate new token**.
2. Expiration: اختار مدة (مثلاً سنة).
3. **Repository access**: Only select repositories ثم اختار ريبو الموقع بس.
4. **Permissions** ثم Repository permissions ثم **Contents = Read and write**.
5. Generate token وانسخه (بيظهر مرة واحدة).
6. افتح `https://USERNAME.github.io/REPO/admin.html`، وهتلاقي اسم الحساب والريبو معبيين لوحدهم، الصق التوكن ودوس دخول.

## 3) الاستخدام
- **الإعدادات العامة:** تليفون، واتساب، إيميل، لينكات السوشيال، ألوان، لوجو.
- **النصوص:** كل كلام الموقع (عربي وإنجليزي)، وإضافة/حذف خدمات.
- **الصور واللينكات:** ارفع صور (لوجوهات عملاء، فيديو، تصوير، جرافيك). **تحت كل صورة خانة لينك**: لو كتبت لينك، الزائر لما يدوس على الصورة يفتح الصفحة دي (بيظهر سهم ↗). بالأسهم غيّر الترتيب، وبـ ✕ احذف.
- دوس **حفظ ورفع على الموقع**: بيترفع كل حاجة في commit واحد، والموقع بيتحدّث خلال دقيقة أو اتنين.

## ملاحظات أمان
- التوكن بيفضل في متصفحك أنت (ولو اخترت "افتكرني" بيتخزن على الجهاز ده)، ومش بيترفع في الموقع. أي حد يفتح `admin.html` مش هيقدر يعمل حاجة من غير التوكن.
- لو اتسرب التوكن أو ضاع الجهاز: جيت هب ثم Settings ثم Fine-grained tokens ثم Delete.
- اللي عنده التوكن يقدر يعدل الموقع كله، فخليه معاك أنت بس. (النسخة دي مفيهاش يوزرات متعددة، دي في نسخة السيرفر.)
- الصور المحذوفة من اللوحة بتفضل ملفاتها في `assets/uploads` على الريبو، وتقدر تمسحها من جيت هب لو حبيت.
- لو اتنين فتحوا اللوحة وحفظ واحد، التاني هيتنبه يحدّث الصفحة قبل الحفظ.

## تعديل يدوي (من غير اللوحة)
ارفع الصورة في `assets/` على جيت هب، وعدّل `content.json` (نصوص + قوائم الصور بشكل `{ "src": "assets/..", "link": "https://.." }`).
